# درایور اینورتر سه‌فاز با STM32F103 — تمام‌خودکفا (بدون HAL)

پروژه‌ای برای تولید **شش سیگنال گیت** جهت درایو **شش ماسفت در سه نیم‌پل** (اینورتر سه‌فاز) با **اختلاف فاز ۱۲۰ درجه**، روی برد **Blue Pill (STM32F103C8T6)**.

## چرا بدون کتابخانه خارجی؟

نسخه‌های قبلی به کتابخانه HAL روی یک مسیر مطلق در کامپیوتر توسعه‌دهنده اصلی ارجاع می‌دادند (`C:/Users/pardazesh/...`) و روی هیچ سیستم دیگری بیلد نمی‌شدند. این نسخه **هیچ وابستگی خارجی ندارد**:

- کتابخانه‌های شخص‌ثالث صفر — فقط فایل‌های داخل همین پوشه
- هدرهای هسته CMSIS (مثل `core_cm3.h`) داخل `Drivers/CMSIS/Include` قرار داده شده‌اند
- رجیسترها در یک هدر کوچک و کاملاً مستند (`Core/Inc/stm32f103_regs.h`) تعریف شده‌اند
- نتیجه: **روی هر کامپیوتری که فقط «کیل» نصب باشد، باز کنید و بیلد بگیرید** — نه اینترنت لازم است، نه نصب پکیج، نه کپی فایل

## ساختار پروژه

```
m12345/
├── Core/
│   ├── Inc/
│   │   ├── main.h              ← تعاریف پایه + توابع عمومی
│   │   ├── stm32f103_regs.h    ← نقشه رجیسترهای مینیمال (مستند، قابل یادگیری)
│   │   ├── tim.h               ← ⭐ تمام تنظیمات اینورتر اینجاست
│   │   ├── gpio.h              ← پروتوتایپ‌های GPIO
│   │   ├── spwm_table.h        ← جدول سینوس ۳۶۰ نقطه‌ای (تولید خودکار)
│   │   └── stm32f1xx_it.h      ← پروتوتایپ هندلرهای وقفه
│   └── Src/
│       ├── main.c              ← کلاک ۷۲ مگاهرتز + موتور مدولاسیون + main
│       ├── tim.c               ← درایور رجیستری TIM1 (PWM + دد‌تایم + Break)
│       ├── gpio.c              ← تنظیم رجیستری پین‌ها
│       ├── stm32f1xx_it.c      ← TIM1_UP_IRQHandler
│       └── system_stm32f1xx.c  ← SystemInit (فایل استارت‌آپ صدایش می‌زند)
├── Drivers/
│   └── CMSIS/Include/          ← هدرهای رسمی هسته ARM (همراه پروژه)
└── MDK-ARM/
    ├── m12345.uvprojx          ← پروژه کیل (باز کنید و بیلد بگیرید)
    └── startup_stm32f103xb.s   ← جدول بردار و استارت‌آپ
```

## بیلد (برای کسی که فقط می‌خواهد اجرا کند)

1. پوشه `MDK-ARM/m12345.uvprojx` را در **Keil µVision** باز کنید.
2. `F7` (Build) بزنید. **تمام.** هیچ پکیج یا نصب اضافه‌ای لازم نیست.
3. با ST-Link فلش کنید (Download).

> اگر محیط دیباگ کیل پیامی درباره پکیج دستگاه داد، نصب `Keil::STM32F1xx_DFP` از Pack Installer اختیاری و فقط برای نمایش رجیسترها در دیباگر است؛ بیلد و فلش بدون آن کار می‌کند.

## خروجی‌ها

| پین | نقش |
|---|---|
| `PA8` | گیت ماسفت **بالای** فاز A (`TIM1_CH1`) |
| `PA9` | گیت ماسفت **بالای** فاز B (`TIM1_CH2`) |
| `PA10` | گیت ماسفت **بالای** فاز C (`TIM1_CH3`) |
| `PB13` | گیت ماسفت **پایین** فاز A (`TIM1_CH1N`، مکمل CH1) |
| `PB14` | گیت ماسفت **پایین** فاز B (`TIM1_CH2N`، مکمل CH2) |
| `PB15` | گیت ماسفت **پایین** فاز C (`TIM1_CH3N`، مکمل CH3) |
| `PB12` | ورودی قطع اضطراری `TIM1_BKIN` (فعال پایین، با پول‌آپ داخلی) |

> پین‌های ۳.۳ ولت را **هرگز مستقیم** به گیت ماسفت قدرت وصل نکنید؛ حتماً از آی‌سی درایور گیت استفاده کنید (مثل IR2110 / IR2104 / EG2104 / FD6288 با تغذیه بوت‌استرپ برای سمت بالا).

## دو مد کاری (`Core/Inc/tim.h`)

### مد `INVERTER_MODE_SPWM` (پیش‌فرض) — مدولاسیون سینوسی
- هر سه فاز، PWM مکمل با حامل **۲۰ کیلوهرتز** تولید می‌کنند.
- دیوتی هر فاز در هر پریود از جدول سینوس به‌روز می‌شود، به‌طوری که **مؤلفه اصلی سه فاز دقیقاً ۱۲۰ درجه** از هم فاصله دارند (ترتیب فاز A→B→C).
- مناسب درایو موتور، خروجی AC سه‌فاز، تغذیه بار سه‌فاز.

### مد `INVERTER_MODE_SIX_STEP` — موج مربعی ۱۲۰ درجه
- سه موج مربعی که هر فاز **۱۲۰ درجه روشن** و ۲۴۰ درجه خاموش است و فازها ۱۲۰ درجه از هم شیفت دارند (الگوی شش‌گام/ذوزنقه‌ای).
- سمت پایین هر نیم‌پل همیشه مکمل سمت بالا (با دد‌تایم سخت‌افزاری روی هر گذار) است.

## جدول تنظیمات (`Core/Inc/tim.h`)

| ماکرو | پیش‌فرض | توضیح |
|---|---|---|
| `INVERTER_MODE` | `SPWM` | انتخاب مد کاری |
| `SPWM_CARRIER_HZ` | `20000` | فرکانس سوئیچینگ |
| `SPWM_ELECTRICAL_HZ` | `50` | فرکانس خروجی سینوسی |
| `SPWM_MODULATION_PCT` | `90` | عمق مدولاسیون (۰..۱۰۰) |
| `SIXSTEP_ELECTRICAL_HZ` | `1000` | فرکانس مد شش‌گام |
| `INVERTER_DEADTIME_NS` | `500` | دد‌تایم برحسب نانوثانیه (حداکثر ~۱۷۶۰) |
| `INVERTER_ENABLE_BREAK` | `1` | فعال بودن ورودی قطع اضطراری |
| `INVERTER_AUTO_REARM` | `1` | شروع خودکار بعد از رفع خطا |

دد‌تایم باید از مجموع تأخیر خاموش‌شدن درایور + ماسفت‌های شما بیشتر باشد (هر تیک تایمر ۱۳.۹ نانوثانیه؛ ۵۰۰ns = ۳۶ تیک).

## ورودی قطع اضطراری (PB12)

- پین باز یا بالا = اینورتر کار می‌کند (پول‌آپ داخلی).
- اتصال به GND (کنتاکت خطا، دکمه، خروجی سنسور جریان) = **خاموش‌شدن سخت‌افزاری هر ۶ خروجی در کمتر از یک سیکل تایمر**، بدون وابستگی به نرم‌افزار.

## راهنمای یادگیری — این پروژه چطور کار می‌کند؟

اگر می‌خواهید از این پروژه یاد بگیرید، این ترتیب را پیشنهاد می‌کنم:

1. **`Core/Inc/stm32f103_regs.h`** — هر رجیستری که استفاده شده با آدرس و بیت‌هایش تعریف شده. مرجع اصلی: دیتاشیت و RM0008 (بخش‌های ۷ برای کلاک، ۹ برای GPIO، ۱۳/۱۵ برای تایمر).
2. **`Core/Src/main.c → SystemClock_Config()`** — مسیر کلاک: کریستال ۸ مگاهرتز → ضرب‌کننده ×۹ در PLL → سیستم ۷۲ مگاهرتز. رجیسترها: `RCC->CR`, `RCC->CFGR`, `FLASH->ACR`.
3. **`Core/Src/tim.c → Inverter_Init()`** — قلب پروژه: رجیسترهای `PSC/ARR` (فرکانس)، `CCMR` (مد کانال)، `CCR` (دیوتی)، `CCER` (فعال‌سازی خروجی‌ها)، `BDTR` (دد‌تایم + ورودی خطا + بیت اصلی `MOE`).
4. **`Core/Src/main.c → Inverter_OnUpdate()`** — منطق مدولاسیون که در وقفه آپدیت تایمر اجرا می‌شود.
5. **`MDK-ARM/startup_stm32f103xb.s`** — جدول بردار: بعد از ریست، `Reset_Handler` ابتدا `SystemInit` و سپس `main` را صدا می‌زند.

### چرا اختلاف فاز ۱۲۰ درجه با یک تایمر ممکن است؟
سه کانالِ یک تایمر شمارنده مشترک دارند و «شیفت فاز کانالی» بی‌معناست؛ اختلاف فاز ۱۲۰ درجه در **محتوای سیگنال** ساخته می‌شود: در مد اسپم، جدول سینوس با زاویه‌های `θ`، `θ+240°` و `θ+120°` ایندکس می‌شود (داخل `Inverter_OnUpdate`)؛ در مد شش‌گام، ماشین حالت هر ۶۰ درجه فاز فعال را عوض می‌کند. در هر دو حالت چون همه‌چیز از **یک شمارنده سخت‌افزاری** می‌آید، فازها ذاتاً هم‌زمان و بدون دریفت هستند.

## اعتبارسنجی انجام‌شده

- هر ۵ فایل با کامپایلر واقعی **ARM (thumb, Cortex-M3) با `-Wall -Wextra -Werror`** بدون هیچ خطا/هشداری کامپایل و سپس **لینک** شدند.
- اندازه کل فیرمور: **~۱.۹ کیلوبایت** (در برابر ۶۴ کیلوبایت فلش).
- مقدار رجیستر `BDTR` در باینری نهایی بررسی شد: دقیقاً `0x5C24` = دد‌تایم ۳۶ تیک + `OSSR` + `OSSI` + `BKE` + `AOE`.
- جدول بردار تأیید شد: `TIM1_UP_IRQHandler` در جای درست (وقفه ۲۵) قرار دارد.
- منطق مدولاسیون (فازهای ۱۲۰ درجه، الگوی شش‌گام) پیش‌تر با شبیه‌سازی عددی نیز تأیید شده است.

## ⚠️ هشدار ایمنی

این مدار با برق قدرت کار می‌کند:
- اولین تست را حتماً با **منبع تغذیه ولتاژ پایین و محدودکننده جریان** انجام دهید.
- قبل از وصل بار قدرت، سیگنال‌های گیت را با اسیلوسکوپ ببینید و مطمئن شوید در هیچ لحظه‌ای هر دو ماسفت یک نیم‌پل همزمان روشن نیستند.
- بین بخش قدرت و منطق، زمین‌ها را درست جدا کنید و از درایور گیت با ایزولاسیون/بوت‌استرپ مناسب استفاده کنید.
