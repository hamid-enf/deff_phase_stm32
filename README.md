# درایور اینورتر سه‌فاز با STM32F103 (تایمر پیشرفته TIM1)

پروژه‌ای برای تولید **شش سیگنال گیت** جهت درایو **شش ماسفت در سه نیم‌پل** (اینورتر سه‌فاز) با **اختلاف فاز ۱۲۰ درجه**، روی برد **Blue Pill (STM32F103C8T6)**.

این نسخه، بازنویسی کامل پروژه قدیمی داخل `m12345.rar` است. نسخه قدیمی سه تایمر عمومی (TIM2/3/4) را با آفست ۱۲۰ درجه استارت می‌زد که «اختلاف فاز» را درست تولید می‌کرد، اما برای درایو واقعی ماسفت‌ها ناکافی و خطرناک بود:

| مشکل نسخه قدیمی | وضعیت در این نسخه |
|---|---|
| فقط ۳ سیگنال (بدون سیگنال مکمل برای ماسفت‌های پایین) | ✅ ۶ خروجی مکمل (CH1/2/3 + CH1N/2N/3N) |
| بدون Dead Time → خطر Shoot-Through و سوختن ماسفت | ✅ دد‌تایم سخت‌افزاری قابل تنظیم در `BDTR` |
| فرکانس ~۲۱۸ کیلوهرتز (غیرمنطقی برای ماسفت قدرت) | ✅ پیش‌فرض ۲۰ کیلوهرتز، قابل تغییر با یک ماکرو |
| بدون حفاظت در برابر خطا | ✅ ورودی Break برای قطع اضطراری سخت‌افزاری |
| سه تایمر مستقل بدون سنکرون | ✅ یک تایمر واحد (TIM1) — فازها ذاتاً هم‌زمان‌اند |

---

## خروجی‌ها

| پین | نقش |
|---|---|
| `PA8` | گیت ماسفت **بالای** فاز A (`TIM1_CH1`) |
| `PA9` | گیت ماسفت **بالای** فاز B (`TIM1_CH2`) |
| `PA10` | گیت ماسفت **بالای** فاز C (`TIM1_CH3`) |
| `PB13` | گیت ماسفت **پایین** فاز A (`TIM1_CH1N`، مکمل CH1) |
| `PB14` | گیت ماسفت **پایین** فاز B (`TIM1_CH2N`، مکمل CH2) |
| `PB15` | گیت ماسفت **پایین** فاز C (`TIM1_CH3N`، مکمل CH3) |
| `PB12` | ورودی قطع اضطراری `TIM1_BKIN` (فعال پایین، با پول‌آپ داخلی) |
| `PA13/PA14` | دیباگ SWD (بدون تغییر) |

> پین‌های ۳.۳ ولت را **هرگز مستقیم** به گیت ماسفت قدرت وصل نکنید؛ حتماً از آی‌سی درایور گیت استفاده کنید (مثل IR2110 / IR2104 / EG2104 / FD6288 با تغذیه بوت‌استرپ برای سمت بالا).

## دو مد کاری

انتخاب مد با ماکروی `INVERTER_MODE` در فایل `Core/Inc/tim.h`:

### ۱) مد `INVERTER_MODE_SPWM` (پیش‌فرض) — مدولاسیون سینوسی
- هر سه فاز، PWM مکمل با حامل **۲۰ کیلوهرتز** تولید می‌کنند.
- دیوتی هر فاز در هر پریود از جدول سینوس به‌روز می‌شود، به‌طوری که **مؤلفه اصلی سه فاز دقیقاً ۱۲۰ درجه** از هم فاصله دارند (ترتیب فاز مثبت A→B→C).
- مناسب برای درایو موتور، خروجی AC سه‌فاز، تغذیه بارهای سه‌فاز.
- پارامترها در `tim.h`: فرکانس حامل (`SPWM_CARRIER_HZ`)، فرکانس خروجی (`SPWM_ELECTRICAL_HZ`، پیش‌فرض ۵۰ هرتز)، عمق مدولاسیون (`SPWM_MODULATION_PCT`، پیش‌فرض ۹۰٪).

### ۲) مد `INVERTER_MODE_SIX_STEP` — موج مربعی ۱۲۰ درجه
- سه موج مربعی که هر فاز **۱۲۰ درجه روشن** و ۲۴۰ درجه خاموش است و فازها ۱۲۰ درجه از هم شیفت دارند (الگوی شش‌گام/ذوزنقه‌ای).
- سمت پایین هر نیم‌پل همیشه مکمل سمت بالا (با دد‌تایم سخت‌افزاری روی هر گذار) است.
- پارامتر: `SIXSTEP_ELECTRICAL_HZ` (پیش‌فرض ۱ کیلوهرتز؛ وقفه هر ۶۰ درجه اجرا می‌شود، پس فرکانس‌های خیلی بالا توصیه نمی‌شود).

## تنظیمات کلیدی (`Core/Inc/tim.h`)

| ماکرو | پیش‌فرض | توضیح |
|---|---|---|
| `INVERTER_MODE` | `SPWM` | انتخاب مد کاری |
| `SPWM_CARRIER_HZ` | `20000` | فرکانس سوئیچینگ |
| `SPWM_ELECTRICAL_HZ` | `50` | فرکانس خروجی سینوسی |
| `SPWM_MODULATION_PCT` | `90` | عمق مدولاسیون (۰..۱۰۰) |
| `SIXSTEP_ELECTRICAL_HZ` | `1000` | فرکانس مد شش‌گام |
| `INVERTER_DEADTIME_NS` | `500` | دد‌تایم برحسب نانوثانیه (حداکثر ~۱۷۶۰) |
| `INVERTER_ENABLE_BREAK` | `1` | فعال بودن ورودی قطع اضطراری |
| `INVERTER_AUTO_REARM` | `1` | شروع خودکار بعد از رفع خطا |

دد‌تایم باید از مجموع تأخیر خاموش‌شدن درایور + ماسفت‌های شما بیشتر باشد. هر تیک تایمر ۱۳.۹ نانوثانیه است (مثلاً ۵۰۰ns = ۳۶ تیک).

## ورودی قطع اضطراری (PB12)

- پین باز یا بالا = اینورتر کار می‌کند (پول‌آپ داخلی).
- اتصال به GND (رله خطا، دکمه، خروجی سنسور جریان) = **خاموش‌شدن سخت‌افزاری هر ۶ خروجی در کمتر از یک سیکل تایمر**، بدون وابستگی به نرم‌افزار.
- با `INVERTER_AUTO_REARM=1` بعد از رفع خطا و در رویداد بعدی تایمر، خروجی‌ها خودکار برمی‌گردند؛ در غیر این صورت باید `Inverter_RearmAfterBreak()` صدا زده شود.

## ساختار فایل‌ها

```
m12345/
├── m12345.ioc              ← تنظیمات CubeMX نسخه قدیمی (فقط برای مرجع؛ بازتولید نکنید!)
├── Core/
│   ├── Inc/
│   │   ├── tim.h           ← تمام تنظیمات اینورتر اینجاست
│   │   └── spwm_table.h    ← جدول سینوس ۳۶۰ نقطه‌ای (تولید خودکار)
│   └── Src/
│       ├── main.c          ← موتور مدولاسیون (اسپم/شش‌گام) در وقفه آپدیت
│       ├── tim.c           ← پیکربندی TIM1: شش خروجی مکمل + دد‌تایم + Break
│       ├── gpio.c          ← پین‌ها + ورودی BKIN
│       └── stm32f1xx_it.c  ← TIM1_UP_IRQHandler
└── MDK-ARM/                ← پروژه کیل (µVision)
```

> ⚠️ فایل `m12345.ioc` متعلق به نسخه قدیمی (TIM2/3/4) است. اگر در CubeMX باز شود و «Generate Code» بزنید، کد جدید از بین می‌رود. همه تنظیمات جدید در `tim.h` و به‌صورت کامنت مستند شده‌اند.

## بیلد با کیل

1. پک‌های `Keil::STM32F1xx_DFP` و `ARM::CMSIS` را در کیل نصب کنید (در بیلد اصلی از `STM32Cube FW_F1 V1.8.6` استفاده شده بود).
2. `MDK-ARM/m12345.uvprojx` را باز کنید و Build بگیرید.
3. با ST-Link پروگرام کنید.

نکته: مسیرهای فایل‌های HAL در پروژه کیل به مخزن محلی `STM32Cube_FW_F1_V1.8.6` روی سیستم اصلی اشاره دارند؛ اگر مسیر شما فرق می‌کند، در تنظیمات پروژه کیل آن‌ها را به محل نصب خودتان تغییر دهید (یا پک کیل جایگزین‌شان می‌شود).

## اعتبارسنجی انجام‌شده

منطق مدولاسیون روی میزبان (gcc) شبیه‌سازی و تأیید شد:
- **مد اسپم**: حامل دقیقاً ۲۰ کیلوهرتز؛ مؤلفه اصلی هر سه فاز دامنه برابر و **فاصله فاز دقیقاً ۱۲۰ درجه** (۹۰° / ۲۱۰° / ۳۳۰°)؛ دد‌تایم ۵۰۰ نانوثانیه؛ هیچ مقدیری خارج از محدوده ثبت نشد.
- **مد شش‌گام**: در هر سکتور ۶۰ درجه دقیقاً یک فاز بالا روشن است؛ A در ۰–۱۲۰°، B در ۱۲۰–۲۴۰°، C در ۲۴۰–۳۶۰°.
- تمام ترکیب‌های تنظیمات (خاموش‌کردن Break، تغییر دد‌تایم، فرکانس‌های مختلف) بدون خطا کامپایل می‌شوند.

## ⚠️ هشدار ایمنی

این مدار با برق قدرت کار می‌کند:
- اولین تست را حتماً با **منبع تغذیه ولتاژ پایین و محدودکننده جریان** انجام دهید.
- قبل از وصل بار قدرت، سیگنال‌های گیت را با اسیلوسکوپ ببینید و مطمئن شوید در هیچ لحظه‌ای هر دو ماسفت یک نیم‌پل همزمان روشن نیستند (دد‌تایم را با درایور خود تنظیم کنید).
- بین بخش قدرت و منطق، زمین‌ها را درست جدا کنید و از درایور گیت با ایزولاسیون/بوت‌استرپ مناسب استفاده کنید.
